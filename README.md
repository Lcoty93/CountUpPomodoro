#Count Up Pomodoro Timer

Is a responsesive productivity application built with React and Vite that reimagines the traditional Pomodoro Technique. Instead of counting down from a preset duration, the timer counts upward. Allowing users to track and focus working sessions, without the stress of watching a counter count down.
